## Постановка задачи

Определите, сколько дней осталось до Нового года, и тему високосного года. Создайте интерфейс, состоящий из кнопки, инпута и двух дивов под ней. Стилизуйте так, чтобы они располагались посередине экрана браузера. Напишите функцию, которая принимает в качестве аргумента значение, введённое в инпут в формате `дд.мм.гггг`, и подсчитывает количество дней до Нового года. При нажатии на кнопку выводит в первый див количество дней, оставшихся от этой даты до Нового года (`31.12.гггг`). Напишите функцию, которая парсит введённую в инпут дату и определяет, является ли год високосным или нет. Напомню, високосный год делится нацело на 4, но не кратен 100. Однако, если кратен 400, то также считается високосным. Эта информация должна отобразиться во втором диве при нажатии на кнопку. То есть, вводим в инпут дату, нажимаем на кнопку и получаем в первом диве количество дней, а во втором информацию — «високосный» или «не високосный». Ответом на задачу будет ссылка на репозиторий GitHub, где хранится Ваша программа, или иной удобный для Вас способ.

## Описание алгоритма

1. **Ввод данных** — пользователь вводит дату в текстовое поле в формате `дд.мм.гггг`.
2. **Парсинг и валидация** — строка разбивается по символу `.` на день, месяц и год; проверяется корректность формата (наличие трёх частей) и корректность самой даты (через `Date.getTime()`).
3. **Расчёт количества дней** — вычисляется разница в миллисекундах между датой 31 декабря текущего года и введённой датой, затем переводится в количество дней.
4. **Проверка високосности** — год проверяется по условию: делится на 4 и не делится на 100, либо делится на 400.
5. **Вывод результата** — количество дней выводится в первый `div`, информация о високосности — во второй.

## Описание объектной модели

| Объект / переменная | Тип | Назначение |
| :--- | :--- | :--- |
| `dateInput` | HTML-элемент `<input>` | Поле ввода даты пользователем |
| `result1` | HTML-элемент `<div>` | Блок вывода количества дней до Нового года |
| `result2` | HTML-элемент `<div>` | Блок вывода информации о високосности года |
| `value` | `string` | Введённая пользователем строка с датой |
| `parts` | `string[]` | Массив из трёх частей даты (день, месяц, год) после разбиения строки |
| `day`, `month`, `year` | `number` | Числовые компоненты даты |
| `date` | `Date` | Объект введённой даты |
| `newYear` | `Date` | Объект даты 31 декабря введённого года |
| `diff` | `number` | Разница между датами в миллисекундах |
| `days` | `number` | Количество дней до Нового года (округление вверх через `Math.ceil`) |

Функция `calculate()` инкапсулирует всю логику задачи: чтение значения из инпута, валидацию, парсинг, вычисление количества дней, проверку високосности и вывод результатов в DOM. Не принимает аргументов, не возвращает значений — работает через побочный эффект (изменение содержимого `div`-блоков).

## Тестовые примеры

Тестовые данные подобраны так, чтобы охватить все ветви алгоритма (корректные даты, некорректный формат, некорректная дата, високосный/невисокосный год, граничная дата).

| № | Входные данные | Ожидаемый результат | Покрываемая ветвь |
| :---: | :--- | :--- | :--- |
| **1** | `15.06.2026` | Дни до НГ: 199 (пример), Год не високосный | Стандартный корректный ввод |
| **2** | `01.01.2028` | Дни до НГ: 365, Год високосный (`2028 % 4 == 0`) | Високосный год |
| **3** | `31.12.2026` | Дни до НГ: 0, Год не високосный | Граничный случай: дата совпадает с Новым годом |
| **4** | `15-06-2026` | «Неверный формат даты» | Некорректный формат (неверный разделитель) |
| **5** | `31.02.2026` | «Некорректная дата» (или некорректная обработка `Date`) | Несуществующая дата |
| **6** | `01.01.2000` | Год високосный (`2000 % 400 == 0`) | Особый случай: год кратен 100, но и 400 |
| **7** | `01.01.1900` | Год не високосный (`1900 % 100 == 0`, но не `% 400`) | Особый случай: год кратен 100, но не 400 |
