## Постановка задачи

Разработать блок-схему алгоритма, написать код программы на языке высокого уровня, составить тестовые примеры исходных данных, которые охватывали бы прохождение всех ветвей алгоритма, составить описание объектных моделей кода. Дан одномерный массив А размерности N. Найти количество элементов, больших заданного числа В и их произведение.

---

## Описание алгоритма

Программа реализует линейный обход одномерного массива с накоплением произведения и счётчика элементов, удовлетворяющих условию `A[i] > B`. Особое внимание уделено граничному случаю, когда таких элементов в массиве нет — в этом случае произведение принудительно обнуляется (чтобы избежать вывода «нейтрального» значения 1.0 при отсутствии подходящих элементов).

Алгоритм состоит из четырёх этапов:
1. **Ввод данных** — пользователь вводит размерность массива N, число B и элементы массива.
2. **Обработка** — последовательный перебор всех элементов массива с проверкой условия `A[i] > B`.
3. **Коррекция результата** — если подходящих элементов не найдено, произведение устанавливается в 0.
4. **Вывод результата** — вывод исходного массива, числа B, количества и произведения подходящих элементов.

## Описание объектной модели

| Объект | Тип | Назначение |
| :--- | :--- | :--- |
| `n` | `int` | Размерность массива (количество элементов) |
| `B` | `float` | Заданное число для сравнения |
| `A` | `list[float]` | Исходный одномерный массив |
| `count_greater` | `int` | Счётчик элементов, больших B |
| `product` | `float` | Накопитель произведения элементов, больших B |
| `element` | `float` | Текущий элемент массива на итерации цикла |

Функция `solve_case_2()` инкапсулирует всю логику задачи: ввод данных, обработку, коррекцию граничного случая и вывод результата. Не принимает аргументов и не возвращает значений (работает через побочный эффект — вывод в консоль).

## Тестовые примеры

Тестовые данные подобраны так, чтобы охватить все ветви алгоритма (наличие/отсутствие подходящих элементов, отрицательные значения, граничное равенство B).

| № | Входные данные (N, A, B) | Ожидаемый результат | Покрываемая ветвь |
| :---: | :--- | :--- | :--- |
| **1** | N=5, A=[3, 8, -2, 10, 5], B=4 | Количество: 3, Произведение: 400.0 | Смешанный случай (есть подходящие и неподходящие элементы) |
| **2** | N=3, A=[5, 6, 7], B=1 | Количество: 3, Произведение: 210.0 | Все элементы больше B |
| **3** | N=3, A=[1, 2, 3], B=10 | Количество: 0, Произведение: 0.0 | Нет элементов больше B |
| **4** | N=1, A=[5], B=5 | Количество: 0, Произведение: 0.0 | Граничный случай: равенство не считается «больше» |
| **5** | N=4, A=[-1, -5, 2, -3], B=-4 | Количество: 3, Произведение: 10.0 | Работа с отрицательными числами |
