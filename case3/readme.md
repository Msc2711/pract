## Постановка задачи

Написать программу с использованием языка программирования Python, которая будет генерировать последовательность случайных чисел до тех пор, пока пользователь не введёт ноль. Вывести на экран все числа, кроме последнего.

---

## Описание алгоритма

Программа реализует цикл с постусловием (`while True` + `break`), на каждой итерации которого генерируется случайное число в диапазоне `[1, 100]`. Сгенерированное число сохраняется в список только в том случае, если пользователь решает продолжить работу (вводит не 0). Если пользователь вводит 0, цикл завершается, а последнее сгенерированное число (предшествующее остановке) в список не попадает — таким образом реализуется условие «вывести все числа, кроме последнего».

Алгоритм состоит из следующих этапов:
1. **Инициализация** — создаётся пустой список для хранения чисел.
2. **Цикл генерации:**
   - генерация случайного числа от 1 до 100;
   - вывод числа на экран;
   - запрос ввода от пользователя;
   - если введён 0 — выход из цикла (число **НЕ** добавляется в список);
   - иначе — число добавляется в список, цикл продолжается.
3. **Вывод итогового результата** — общее количество сгенерированных чисел, количество чисел в списке и сам список (либо сообщение, если список пуст).

## Описание объектной модели

| Объект | Тип | Назначение |
| :--- | :--- | :--- |
| `numbers` | `list[int]` | Список сохранённых сгенерированных чисел (без последнего) |
| `random_number` | `int` | Очередное случайное число, сгенерированное на текущей итерации |
| `user_input` | `int` | Число, введённое пользователем (0 — сигнал остановки) |

Функция `solve_case_3()` инкапсулирует всю логику задачи: генерацию случайных чисел, взаимодействие с пользователем и вывод результата. Не принимает аргументов и не возвращает значений (работает через побочный эффект — вывод в консоль). Используется модуль `random` как внешняя зависимость для генерации псевдослучайных значений.

## Тестовые примеры

Тестовые данные подобраны так, чтобы охватить все ветви алгоритма (немедленная остановка, несколько итераций, единичная итерация).

| № | Сценарий ввода пользователя | Ожидаемый результат | Покрываемая ветвь |
| :---: | :--- | :--- | :--- |
| **1** | Сразу вводится `0` | `numbers = []`, выводится сообщение «нет чисел для вывода», всего сгенерировано чисел: 1 | Граничный случай: немедленная остановка |
| **2** | Вводится: `1, 1, 0` (3 итерации) | `numbers` содержит 2 числа, всего сгенерировано чисел: 3 | Обычный случай: несколько итераций перед остановкой |
| **3** | Вводится: `5, 0` (2 итерации) | `numbers` содержит 1 число, всего сгенерировано чисел: 2 | Единичная итерация перед остановкой |
| **4** | Вводится: `1, 1, 1, 1, 0` (5 итераций) | `numbers` содержит 4 числа, всего сгенерировано чисел: 5 | Длинная последовательность итераций |

> **Примечание:** поскольку числа генерируются случайным образом (`random.randint(1, 100)`), при тестировании фиксируется не конкретное значение числа, а корректность логики накопления списка и подсчёта количества итераций.
