## Постановка задачи

Необходимо спроектировать блок-схему, реализовать программный код на одном из языков высокого уровня, а также подготовить набор тестовых данных для проверки всех возможных путей выполнения (ветвей) алгоритма. Дополнительно требуется привести описание объектных моделей. 

**Исходные данные:** одномерный массив A, состоящий из N элементов.  
**Цель:** вычислить сумму и определить количество элементов массива, которые строго больше нуля.

---

## Логика работы алгоритма

Решение базируется на последовательном переборе (линейном обходе) массива. В процессе итераций происходит агрегация двух величин: общей суммы и счетчика для тех ячеек, где выполняется условие `A[i] > 0`.

Рабочий процесс разделен на три основные стадии:
1. **Инициализация и ввод:** с клавиатуры считывается длина массива (N) и значения его элементов.
2. **Вычисления:** организуется цикл для прохода по всем элементам. На каждом шаге проверяется знак числа: если текущий элемент положительный, его значение прибавляется к общей сумме, а счетчик увеличивается на единицу.
3. **Формирование ответа:** на экран выводится сам исходный массив, а также итоговые результаты — количество и сумма найденных положительных чисел.

## Описание объектной модели

| Объект | Тип | Назначение |
| :--- | :--- | :--- |
| `n` | `int` | Размерность массива (количество элементов) |
| `A` | `list[float]` | Исходный одномерный массив |
| `sum_positive` | `float` | Накопитель суммы положительных элементов |
| `count_positive` | `int` | Счётчик положительных элементов |
| `element` | `float` | Текущий элемент массива на итерации цикла |

Функция `solve_case_1()` инкапсулирует всю логику задачи: ввод данных, обработку и вывод результата, не принимает аргументов и не возвращает значений (работает через побочный эффект — вывод в консоль).

## Тестовые примеры

Тестовые данные подобраны так, чтобы охватить все ветви алгоритма (наличие/отсутствие положительных элементов, граничные случаи нуля).

| № | Входные данные (N, массив) | Ожидаемый результат | Покрываемая ветвь |
| :---: | :--- | :--- | :--- |
| **1** | N=5, A = [3, -2, 7, 0, -1] | Количество: 2, Сумма: 10.0 | Смешанный случай (есть и положительные, и отрицательные) |
| **2** | N=3, A = [1, 2, 3] | Количество: 3, Сумма: 6.0 | Все элементы положительные |
| **3** | N=3, A = [-1, -2, -3] | Количество: 0, Сумма: 0.0 | Нет положительных элементов |
| **4** | N=1, A = [0] | Количество: 0, Сумма: 0.0 | Граничный случай: ноль не считается положительным |
| **5** | N=0 | Количество: 0, Сумма: 0.0 | Пустой массив (цикл не выполняется) |
